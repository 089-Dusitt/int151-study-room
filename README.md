# ห้องติว INT151

เว็บอ่านสอบ INT151 Exam 02 ภาษาไทย ใช้ได้ทั้งคอมพิวเตอร์และมือถือ

**เปิดเว็บ:** https://089-dusitt.github.io/int151-study-room/

- บทเรียน 22 บท รวมจุดที่อาจารย์เน้นจาก G1/G2
- ข้อเท็จจริง 88 ข้อ พร้อมคำอธิบายที่อ่านได้ทันที
- แบบฝึกภาษาอังกฤษ 40 ข้อ พร้อมคำแปลและเหตุผลภาษาไทย
- จำลองสอบ 30 ข้อใน 60 นาที เลือกขาดหรือเกินได้ 0 คะแนน
- โจทย์ปฏิบัติ 6 ชุด พร้อมคำใบ้ แนวทาง และรายการตรวจงาน
- ความคืบหน้าและข้อที่พลาดเก็บในเบราว์เซอร์ของผู้ใช้

แบบฝึกสร้างเพื่อทบทวน ไม่ใช่ข้อสอบจริง และไม่รับประกันผลคะแนนหรือเกรด

## อัปเดตเว็บไซต์

แก้ไฟล์เว็บใน `dist/` แล้ว push ไป `main` GitHub Actions จะตรวจข้อมูลและเผยแพร่ GitHub Pages อัตโนมัติ ไม่ต้องติดตั้ง npm packages หรือ build

ตรวจข้อมูลในเครื่องด้วย Node.js 22 ขึ้นไป:

```sh
npm run check
```

Repository นี้มีเฉพาะเว็บไซต์และตัวตรวจข้อมูล ไม่รวม PDF, transcript ต้นฉบับ, ข้อมูลความคืบหน้าของผู้เรียน หรือไฟล์เชื่อมต่อบริการส่วนตัว
